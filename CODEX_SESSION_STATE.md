# Nexa Codex Session State

## Current task — Nexa 0.1.13 Alpha

Prior architecture: Pixel Swarm was launched by **I'm bored**, moved the dashboard's timer pixels into a full-window arena, and used the same frame ticker while dashboard/session clocks and autosave continued. Movement and shooting were mouse-driven, with a single survival pattern and no separate player health or persistent game stats.

Current architecture: `PixelSwarmGame` owns run-only entities and phase (`Menu`, `Playing`, `Paused`, `LevelUp`, `GameOver`); `SwarmArena` renders those entities in WPF; `MainWindow.Boredom.cs` owns the overlay, HUD and input mapping. `PixelSwarmRules.cs` centralizes balance, enemy/weapon/pickup kinds and owner-scoped local score storage. The game loop advances with bounded delta time and stops only its own simulation when paused or leveling. It does not change dashboard state, the original session timestamps, or the autosave timer.

Controls: WASD/arrows move with normalized diagonal speed, the mouse aims in arena DIPs, left click fires one starter Pixel Blaster shot, and holding fires only with the limited Machine Gun. Esc pauses/resumes; menu actions restart or return. Stage 1 drifts timer pixels, Stage 2 adds pursuing enemies and moving white relief orbs, and Stage 3 adds dashers, shooters, tanks, enemy multiplication, weapon pickups and elite variants. Bosses appear on later stage milestones. Health starts at 3 HP with hit invulnerability. Relief slows pressure; health, shield, rapid fire, Machine Gun and Grenade Launcher pickups and three-choice XP upgrades provide survival options. Score, stage, kills and time appear on the game-over screen; per-user best score, longest run, highest stage and totals live outside Space exports in an atomically written preferences file.

Appearance root cause: per-Space `ApplyColors()` reloaded the stored global palette, reverting newly selected mode/accent before it persisted; direct brush references in live and detached Settings controls could also keep old colors. Fix: apply the global palette once on startup/selection, retarget old direct brushes, refresh detached Settings pages, and derive Space chrome from the global palette while preserving explicit per-Space accent/pixel colors. Light, Dark and alternate accents update immediately and persist.

Performance: enemies, shots, pickups and particles have caps; projectile collisions use swept rectangles; timer seeds are sampled to the Stage 1 cap; frame delta is bounded after stalls. No new dependency or saved dashboard schema migration. Changed `BoredomGame.cs`, `MainWindow.Boredom.cs`, `MainWindow.xaml.cs`, `Theme.cs`, `SettingsDialog.cs`, project/manifest version, docs and test dispatch. Added `PixelSwarmRules.cs` and `tests/Swarm013Checks.cs`.
