# 🎃 A smoother Space for whatever haunts you next

**Nexa Beta 0.1.2 is here!** A clearer welcome, sharper everyday controls, and a more dependable Pixel Timer make it easier to settle into your next Space.

This update includes the previously local Beta 0.1.1 improvements and preserves the Beta 0.1.0 release.

## ✨ What’s new

- **A welcome that stays focused.** First launch shows onboarding on its own. Choose from the complete widget library, preview Light or Dark instantly, and decide whether to enable Nexaween on the final page.
- **Make your Space yours.** A compact icon grid supports keyboard selection. Create Space has a visible, centered label and wrapping widget choices. Profile keeps its polished card and inline rename editor, with Rerun Setup available in Profile and Developer Mode.
- **More dependable sessions.** Session Settings retain edits after a failed save and offer Retry, Discard, or Cancel. AM/PM and duration previews are clearer, overnight schedules are supported, and applied schedules refresh the Pixel Timer immediately.
- **Three new pixel shapes.** Add Triangle, Octagon, or pixelated Hearts alongside Square and Circle, with an immediate preview and saved preferences.
- **Cleaner windows.** Neutral outer borders, consistent rounded corners, and darker Light Mode icons improve readability. First-launch placement fits the work area while later window positioning remains unrestricted.
- **A calmer installer.** The duplicate loading bar that could cover status text is removed. Scan for old versions directly from Welcome, review the results, and return without installing. Setup distinguishes verified application processes from itself and can request graceful closure without force-terminating an app.
- **Safer maintenance.** Mandatory clean-install cleanup preserves adjacent private files, Repair Files skips shortcut prompts, and Rerun Installer verifies a local installer before offering a trusted download when needed.

HEDY is preserved; the retired HEVY entry is removed. Existing Bug Battle behavior and the eight-leg spider correction remain included. New combat expansions and Nexy are reserved for later releases.
