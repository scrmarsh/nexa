# nexa 0.1.25 Alpha manual acceptance

Status: **not yet approved**. Automated checks use isolated data. A checkbox below is not a pass until a person records the date, machine, configuration and result. Keep the approved executable and a private backup of user data. Do not publish a release or promote Testing to Latest from this checklist automatically.

## Reliability and time

- [ ] On a copy of a real Space, open History, search/date-filter, edit an archived note, export, reopen, and confirm every available recorded field. Test empty and corrupt histories without deleting their originals.
- [ ] Exercise all autosave intervals; edit notes/tasks/water/pins between checkpoints. Verify failure feedback and refusal to reset when saving fails.
- [ ] Hibernate immediately after an edit. Resume before/after class end, post-session checkpoint and next pre-session reset. Confirm saved content, no duplicate session, warning/postponement and correct reset scopes.
- [ ] Manual/Schedule timer modes, M/W and arbitrary days, midnight, week end, changing selected zone and a real DST transition fixture. Compare linked progress and actual clock seconds. Reset appears only in Manual mode.

## Navigation and layout

- [ ] Use actual mouse/trackpad/keyboard on all time and bug selectors. Switch Settings tabs repeatedly; ensure one window, retained position, centered reopening, drag title and continuous rounded borders.
- [ ] Six initial Space cards/two columns, repeated Show More, scrolling and opening an older Space. All saved Spaces remain accessible.
- [ ] Drag/resize/add widgets below the last row; edge autoscroll; reopen and verify placement. Test tips right/autosave left in windowed/maximized/fullscreen on 100/125/150/200% monitors and with the taskbar on different edges. Inspect long text/dismiss controls.

## Branding and effects

- [ ] Turn Nexaween on/off/restart: home, window/taskbar icon, splash and wordmark. Normal blue/purple must return. The packaged executable shell icon is fixed seasonal and Windows caches icons; this remains a known limitation.
- [ ] Watch the full lowercase tagline; haunts must start orange at its first letter. Splash shows logo alone about three seconds, then real loading stages.
- [ ] Inspect Home/dashboard/Appearance actors for stationary 5–10-second holds, independent fades, balanced candy-weighted distribution, all ten categories and no blocked text/controls.
- [ ] Static corner web/spider never moves; no-face pumpkin remains in the home corner. Move/resize/scroll decorated widgets: only 2–3 corners, vines stay attached. Extensive organic/right-edge vine polish and dedicated vine crawl surfaces remain incomplete.
- [ ] Toggle reduced motion, effects and seasonal animation while actors and streak popup are active. No strobing, residual animation clocks or disruptive focus.

## Bugs and productivity

- [ ] All six species, All Bugs rebalance, three independent behaviors and three appearances, Adorable on/off, sizes and quality selections after restart.
- [ ] Sustained 30–60-minute Infestation run: record FPS, UI latency, memory, CPU, spawn throttling and save responsiveness. Target ~20 FPS; no hardware certification has been recorded.
- [ ] Spiders: circular irregular webs, construction, stable scrolling, home/return behavior. Flies: takeoff/hover/land/groom; ants/ladybugs/roaches/centipedes: anatomically appropriate legs and movement.
- [ ] Cozy bugs approach visible candy, pause to eat, consume it, and get replacement candy; fade must not interrupt eating. Repeat with reduced motion and seasonal animation disabled.
- [ ] Damage flash/tears end promptly; no yellow target ring or squash-triggered full-window green effect. Normal controls remain clickable; toolbar stays clear.
- [ ] Squash species and total counters update/persist; historical unknown-species counts stay unknown. Combined Productivity preserves prior configuration. Existing dual legacy placements are not automatically removed.
- [ ] Bonus starts/refreshes for two minutes, increases by 0.5 to the configured maximum, expires for actual scoring immediately, and visually decays without losing earned points. Centered popup reuses one layer.

## Integrations, sound and updates

- [ ] Preview every cue on a real sound device at configured volume and mute. Check no overlapping cue storms.
- [ ] Todoist/Hedy real-account smoke tests, Hedy recording/transcript access and existing Google/Outlook connections. Hedy and Hevy are distinct; Hevy is not implemented and provider/order clarification remains open.
- [ ] In an isolated portable installation, use the actual Updates UI: live check, notes, download cancellation, prepare confirmation, backup, restart confirmation, helper install, relaunch, induced failure/rollback and interrupted resume. Never test against the approved/root installation or publish a test production release.

## Approval

Record failures and screenshots privately. Approve/promote/publish only through a subsequent explicit release decision after the outstanding requirements and manual checks are resolved. This candidate does not certify completion of all Nexaween requirements.
