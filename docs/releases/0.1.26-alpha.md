# nexa v0.1.26 alpha — Spaces in Motion

**a space for whatever comes next**

A more useful Space from first setup to the end of a session, with cumulative productivity, interactive guidance and refined optional Nexaween artwork.

## Download

Download **Nexa.exe** from Assets and run it on Windows x64. This is a self-contained portable .NET 10/WPF build. Keep your existing saved data; do not remove the Windows LocalAppData SessionDashboard folder.

This alpha executable is not code-signed. SHA256SUMS.txt identifies the exact download; inspect it with Get-FileHash ./Nexa.exe -Algorithm SHA256.

## Productivity and session completion

- Persistent cumulative productivity totals per Space, with session starting/ending score snapshots and recorded-event deduplication.
- Click collectible candy for one base point and a shared streak increase of 0.5x, subject to the existing cap and rate protection.
- Circular Productivity widget with animated score/progress and a brief pulse.
- Dedicated End Session action saves before finalization, prevents duplicate completion and provides approximately one second of visual Pixel Timer completion when ending early.
- Animated recap with recorded accomplishments, score comparison and return-to-Dashboard/Home actions. Actual elapsed time stays distinct from the completion animation.
- Automatic safe saving and recovery retain existing layouts, settings and records.

## Getting comfortable

- Interactive Quick Start spotlights teach adding, moving, resizing and renaming real widgets, with skip, replay and restart recovery.
- Refined setup cards, optional integration introductions, independent appearance/sound controls and separate manual/schedule Pixel Timer drafts.
- Six initial recent-Space cards, expandable older Spaces, saved Space icons, lazy Settings pages and safer navigation preparation.

## Optional Nexaween details

- A larger Home corner web and slowly moving web-bound spider.
- One naturally rounded pumpkin body with carved candlelit features and internal rib shading.
- Earthy green vines connected to the stalk, including long window-edge branches, curls and leaves.
- Pumpkins attached to available widget corners, preserving world coordinates through scrolling and resizing.
- Theme/border/logo transitions respect reduced-motion preferences. Seasonal artwork remains noninteractive around normal controls.

## Known alpha limitations

- Physical mixed-DPI/multi-monitor interaction and all visual transitions are not fully certified.
- Genuine Windows hibernate/crash recovery and migration of an approved private saved-data fixture still need manual testing.
- Live Todoist, Hevy and Hedy accounts, and updating a real installed older release, were not exercised. Updater validation used isolated synthetic data.
- Extended-session memory and live high-density rendering FPS remain unverified.
- Navigation profiling showed a remaining Space-load latency outlier. These results do not establish universal performance improvements.

No previous GitHub release assets are replaced by this release.
