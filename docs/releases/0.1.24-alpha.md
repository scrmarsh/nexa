**A space for whatever haunts you next.**

Nexa 0.1.24 Alpha brings the essentials together: recurring sessions, reliable saving, readable history and a dashboard with room to grow. NEXAWEEN adds a little candy, a little crawling and plenty of personality.

## Download and run

Download **Nexa.exe** under **Assets**, place it in a folder you control, and run it on **Windows x64**. This self-contained executable includes .NET 10; no installer or separate runtime is required. Existing Spaces, presets, notes, history and settings remain in the established LocalAppData location.

`SHA256SUMS.txt` contains the executable's SHA-256 checksum. Compare it with `Get-FileHash .\Nexa.exe -Algorithm SHA256`. This Alpha executable is not code-signed.

## The Archives Awaken

- State reads wait for an in-flight checkpoint, preventing transient file replacement from loading empty defaults.
- Searchable session history, continuous/event-driven saving and configurable autosave intervals.
- Recovery records and save-before-reset safeguards preserve work and review time.
- One Session entry brings together saving, history and tips; the Timeline retains its Hedy and recording purpose.

## Time Is Under a Spell

- The Pixel Timer fills from the top-left during class and clears in reverse while counting down to the next session.
- Recurring weekdays, date/duration editing, selected time zones and three-decimal progress precision.
- Linked progress bars share authoritative timestamps; independent bars retain their own ranges.

## The Dashboard Has Been Haunted

- Nexaween branding, the seasonal changelog palette and candy-only backgrounds.
- Pumpkins and vines use actual widget targets, remain aligned during layout changes and stay clear of controls.
- Classic, Cozy, Creepy and Combative modes, six seasonal costumes and species-specific movement.
- Persistent spider-owned webs remain separate from seasonal decoration placement.
- Productivity Meter, score breakdowns and bounded two-minute squash streaks.

## A tidier home for Nexa

Retired story code, old pre-naming-scheme material and mixed development logs are preserved in `LEGACY`, excluded from the current build. Source, development instructions and current release notes have clear homes; generated builds and personal data stay out of Git.

## Verification and remaining checks

The release is built as a self-contained Windows x64 single-file application and receives an isolated packaged-startup check, including embedded offline resources. The ten-route automated suite covers core functionality, reliability, timing, scrolling/layout, menus, the ecosystem and animations.

Physical sleep/hibernation, live provider/microphone integrations and extended mixed-DPI/GPU sessions still need manual acceptance. Procedural creature movement is stylized; detailed cooperative choreography remains future polish.
