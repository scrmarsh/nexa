# nexa v0.0.33 alpha

**[Download nexa for Windows — recommended installer](https://github.com/scrmarsh/nexa/releases/download/v0.0.33-alpha/NexaSetup.exe)**

The official current-user installer adds nexa to Windows Installed Apps and the Start menu, offers a desktop shortcut and supports repair and uninstall. Existing private saves stay in your Windows account. Uninstall keeps them by default; removing private data requires explicit confirmation.

- One app in installer and portable formats, with update support retained in both. Installed updates use verified Setup packages, save your work and show a 30-second restart countdown with Restart now and Later.
- Backed-up migration and optional cleanup of verified old portable copies. Unrelated files and unverified copies are preserved.
- Home → Files provides easy access to private data, Space exports and readable history documents. Exported notes and transcripts can contain private information; share intentionally.
- Appearance scrolls fully with its scrollbar hidden. Exactly four official palettes remain available: nexa, Violet, Aurora and Ember. Classic choices and wallpapers stay saved independently while nexaween uses its seasonal styling.
- Laptop-safe bounds, game stability, independent sound choices, batched bug saves, existing providers, Space history and the approved seasonal artwork are retained.

**Older .24/.26 users:** install using the recommended download once. Their existing comparator can reject newer canonical Alpha versions; release metadata cannot patch that old code. Compatible .29/.31 updaters receive a migration launcher that opens the installer.

This is an **Alpha prerelease**, not Beta or stable. Windows packages are currently unsigned. Physical precision-trackpad feel and complete multi-monitor/DPI hardware acceptance remain open; native and automated results are recorded in the verification report.
